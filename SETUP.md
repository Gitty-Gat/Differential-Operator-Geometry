# SETUP

_Last updated: 2026-04-08_

This repository is intentionally lightweight. There is no `pyproject.toml`, no `setup.py`, and no Makefile; the current runnable path is a plain Python environment with `numpy` installed and `src/` placed on `PYTHONPATH`.

## Prerequisites
- Python 3.11+ recommended
- `venv` support available (`python3 -m venv`)
- Git

## Quick start
From the repository root:

```bash
python3 -m venv .venv
. .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

The only declared dependency right now is:
- `numpy`

## Repository layout that matters for execution
- `src/rest/` — core REST implementation
- `src/baselines/` — baseline coordinate transforms
- `tests/` — unit tests
- `experiments/synthetic/` — reproducible synthetic experiment entry points
- `experiments/results/` — generated metrics and figures

## Important execution rule
The code is imported directly from `src/`, so commands should be run from the repository root with `PYTHONPATH=src`.

Examples below assume either:
- the virtual environment is activated, or
- commands are prefixed with `.venv/bin/python` explicitly.

## Run the unit tests
```bash
PYTHONPATH=src python -m unittest discover -s tests -v
```

Equivalent without activating the virtual environment:

```bash
PYTHONPATH=src .venv/bin/python -m unittest discover -s tests -v
```

## Run the synthetic experiment scripts
Phase 3 synthetic evaluation:

```bash
PYTHONPATH=src python experiments/synthetic/run_phase3.py
```

Phase 4 synthetic evaluation and figure generation:

```bash
PYTHONPATH=src python experiments/synthetic/run_phase4.py
```

Equivalent explicit-venv commands:

```bash
PYTHONPATH=src .venv/bin/python experiments/synthetic/run_phase3.py
PYTHONPATH=src .venv/bin/python experiments/synthetic/run_phase4.py
```

## Minimal reproducibility checklist
1. Create or refresh `.venv`.
2. Install `requirements.txt` into that environment.
3. Run tests with `PYTHONPATH=src`.
4. Run the synthetic experiment scripts from repo root.
5. Confirm updated metrics/figure artifacts land under `experiments/results/`.

## Common failure modes

### `ModuleNotFoundError: No module named 'numpy'`
The active interpreter does not have the declared dependency installed.

Fix:

```bash
python -m pip install -r requirements.txt
```

or, if using the repo-local environment explicitly:

```bash
.venv/bin/python -m pip install -r requirements.txt
```

### `ModuleNotFoundError: No module named 'rest'` or `baselines`
This usually means the command was run without `PYTHONPATH=src` or from outside the repository root.

Fix:

```bash
cd /path/to/Differential-Operator-Geometry
PYTHONPATH=src python -m unittest discover -s tests -v
```

### The repo has an old `.venv` but commands still fail
Recreate the environment cleanly:

```bash
rm -rf .venv
python3 -m venv .venv
. .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

## Current setup scope
This setup is sufficient for:
- unit tests,
- synthetic stream experiments,
- reproducing the current retained-coordinate covariance-based REST results.

It is not yet packaged as an installable library, and there is no task runner abstraction. That is deliberate for now; the priority is reproducible research iteration, not packaging polish.
