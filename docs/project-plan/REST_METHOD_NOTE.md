# REST_METHOD_NOTE

## Purpose
This note gives the first formal specification of **REST** (Reciprocal–Exponential Spectral Transforms) in the canonical covariance-based setting adopted by the repository. After Phase 4, the most accurate framing of this object is:

> REST is a **streaming geometric preconditioner** in retained spectral coordinates.

The goal is intentionally narrow:

1. fix one mathematical setting,
2. define one retained-coordinate preconditioning transform with consistent notation,
3. state one modest single-step stability theorem target,
4. provide an algorithm description aligned with that theorem target.

This note does **not** claim that REST is already fully characterized, globally near-isometric, or empirically superior to existing methods. It only formalizes the initial covariance-based operator version needed for rigorous follow-up work.

---

## Canonical setting
Let `(x_t)_{t \ge 1}` be a stream of observations in `\mathbb{R}^d`. In the current repository state, REST should be interpreted as a **retained-coordinate geometric preconditioner** applied to a local covariance-based representation. For each time `t`, choose a finite sliding window

```math
W_t = \{x_{t-m+1}, \dots, x_t\}
```

of length `m \ge 2`, or any equivalent local sample set used to define a time-local geometry.

Define the windowed mean

```math
\mu_t = \frac{1}{m}\sum_{s=t-m+1}^{t} x_s
```

and the centered current sample

```math
\tilde{x}_t = x_t - \mu_t.
```

The canonical local operator is the windowed covariance matrix

```math
L_t := \frac{1}{m}\sum_{s=t-m+1}^{t} (x_s-\mu_t)(x_s-\mu_t)^\top \in \mathbb{R}^{d\times d}.
```

Then `L_t` is symmetric positive semidefinite.

For a chosen retained rank `k \le d`, let

```math
L_t = U_t\Lambda_t U_t^\top + U_{t,\perp}\Lambda_{t,\perp}U_{t,\perp}^\top
```

be an eigendecomposition ordered so that

```math
\lambda_{t,1} \ge \lambda_{t,2} \ge \cdots \ge \lambda_{t,d} \ge 0,
```

with retained basis

```math
U_t = [u_{t,1}, \dots, u_{t,k}] \in \mathbb{R}^{d\times k}
```

and retained eigenvalue matrix

```math
\Lambda_t = \operatorname{diag}(\lambda_{t,1}, \dots, \lambda_{t,k}).
```

REST is defined primarily in the retained coordinate system generated by `U_t`, not as a full ambient-space operator.

## Notation
We use the following symbols throughout.

### Data and operator objects
- `x_t \in \mathbb{R}^d`: incoming observation at time `t`
- `W_t`: local window used to define the current operator
- `\mu_t \in \mathbb{R}^d`: window mean
- `\tilde{x}_t = x_t - \mu_t`: centered current observation
- `L_t \in \mathbb{R}^{d\times d}`: windowed covariance operator
- `k`: retained rank

### Spectral objects
- `U_t \in \mathbb{R}^{d\times k}`: retained eigenbasis
- `\Lambda_t = \operatorname{diag}(\lambda_{t,1},\dots,\lambda_{t,k})`: retained eigenvalue matrix
- `P_t = U_tU_t^\top`: projector onto the retained eigenspace

### Coordinates and transforms
- `c_t = U_t^\top \tilde{x}_t \in \mathbb{R}^k`: retained raw spectral coordinates
- `D_{\mathrm{inv}}(\Lambda_t, r_t) \in \mathbb{R}^{k\times k}`: reciprocal weighting matrix
- `D_{\exp}(\Lambda_t, r_t, \beta) \in \mathbb{R}^{k\times k}`: exponential lift matrix
- `W_t = D_{\exp}(\Lambda_t, r_t, \beta)D_{\mathrm{inv}}(\Lambda_t, r_t)`: composite diagonal weight matrix
- `z_t = W_t c_t \in \mathbb{R}^k`: REST output coordinates
- `T_t = W_tU_t^\top \in \mathbb{R}^{k\times d}`: retained-coordinate transform so that `z_t = T_t\tilde{x}_t`

### Parameters
- `r_t > 0`: reciprocal damping or ridge scale
- `\beta \ge 0`: exponential lift gain
- `\phi(\lambda; r_t)`: shaping function used in the exponential lift
- `a_{\min}, a_{\max}`: clipping bounds for reciprocal weights
- `b_{\min}, b_{\max}`: clipping bounds for exponential weights

The historical shorthand `r^{e^2}` is not used here. Future formal documents should use explicit parameter and transform notation.

## Formal REST transform in retained coordinates

### Step 1: retained coordinates
Given the centered sample `\tilde{x}_t`, define

```math
c_t := U_t^\top \tilde{x}_t \in \mathbb{R}^k.
```

### Step 2: reciprocal spectral flattening
Define diagonal reciprocal weights

```math
w^{\mathrm{inv}}_{t,i} := \psi_{\mathrm{inv}}(\lambda_{t,i}; r_t), \qquad i=1,\dots,k,
```

where `\psi_{\mathrm{inv}}` is a bounded reciprocal-type map. A canonical example is

```math
\psi_{\mathrm{inv}}(\lambda; r_t)
=
\operatorname{clip}\!\left((\lambda+r_t)^{-1/2},\, a_{\min},\, a_{\max}\right).
```

Set

```math
D_{\mathrm{inv}}(\Lambda_t, r_t)
:=
\operatorname{diag}(w^{\mathrm{inv}}_{t,1},\dots,w^{\mathrm{inv}}_{t,k}).
```

### Step 3: exponential spectral lift
Define diagonal lift weights

```math
w^{\exp}_{t,i} := \psi_{\exp}(\lambda_{t,i}; r_t, \beta), \qquad i=1,\dots,k,
```

where `\psi_{\exp}` is a bounded exponential-type map. A canonical example is

```math
\psi_{\exp}(\lambda; r_t, \beta)
=
\operatorname{clip}\!\left(\exp(\beta\,\phi(\lambda; r_t)),\, b_{\min},\, b_{\max}\right).
```

Set

```math
D_{\exp}(\Lambda_t, r_t, \beta)
:=
\operatorname{diag}(w^{\exp}_{t,1},\dots,w^{\exp}_{t,k}).
```

### Step 4: composite REST coordinates
The retained-coordinate REST transform is

```math
W_t := D_{\exp}(\Lambda_t, r_t, \beta)D_{\mathrm{inv}}(\Lambda_t, r_t) \in \mathbb{R}^{k\times k},
```

and the output is

```math
z_t := W_t c_t.
```

Equivalently,

```math
T_t := W_tU_t^\top,
\qquad
z_t = T_t\tilde{x}_t.
```

The canonical implementation is written in reciprocal-then-exponential order. However, in the current retained-coordinate diagonal formulation both weighting maps are diagonal in the same basis, so their product commutes algebraically. As a result, the current method note should treat the transform primarily as a **composite geometric preconditioner**, not as evidence that ordering itself is yet a distinct source of benefit.

## Assumptions
The first theorem only uses a modest assumption set.

### A1. PSD operator
For each `t`, `L_t` is symmetric positive semidefinite.

### A2. Retained spectral gap
There exists `\gamma > 0` such that

```math
\lambda_{t,k} - \lambda_{t,k+1} \ge \gamma
```

whenever the `(k+1)`st eigenvalue is defined.

### A3. Bounded one-step operator drift
There exists `\delta \ge 0` such that

```math
\|L_t - L_{t-1}\|_2 \le \delta.
```

### A4. Bounded transform laws
The scalar maps `\psi_{\mathrm{inv}}` and `\psi_{\exp}` are bounded on the relevant spectral interval, and their product

```math
g(\lambda, r_t) := \psi_{\exp}(\lambda; r_t, \beta)\,\psi_{\mathrm{inv}}(\lambda; r_t)
```

is uniformly Lipschitz in `\lambda` on the retained spectral range.

### A5. Bounded parameters
The damping scales satisfy

```math
0 < r_{\min} \le r_t \le r_{\max} < \infty.
```

### A6. Bounded centered data
When translating operator stability into output-coordinate stability, assume there exists `B_x < \infty` such that

```math
\|\tilde{x}_t\|_2 \le B_x
```

for the inputs under consideration.

## First theorem statement
### Theorem 1 (single-step stability of the retained REST transform)
Assume A1–A5. Define

```math
\mathcal{R}_t := U_tW_tU_t^\top.
```

Then there exists a constant `C_{\mathrm{op}} > 0`, depending only on the uniform weight bounds, the Lipschitz constant of the composite weight law, and the spectral-gap control, such that whenever

```math
\|L_t-L_{t-1}\|_2 \le \delta
```

and the spectral gap assumption holds at times `t-1` and `t`, one has

```math
\|\mathcal{R}_t - \mathcal{R}_{t-1}\|_2 \le C_{\mathrm{op}}\,\delta
```

for sufficiently small `\delta` relative to the retained gap `\gamma`.

If in addition A6 holds, then there exists `C_{\mathrm{out}} > 0` such that

```math
\|z_t-z_{t-1}\|_2
\le
C_{\mathrm{out}}\,\delta
+
\|W_{t-1}\|_2\,\|U_t^\top\tilde{x}_t-U_{t-1}^\top\tilde{x}_{t-1}\|_2.
```

### Interpretation
This theorem is intentionally modest. It does **not** claim:
- long-horizon stability under arbitrary repeated updates,
- near-isometry,
- angle preservation,
- or superiority over PCA/whitening.

It only states that, under a retained spectral gap and bounded transform laws, the one-step REST operator is stable under one-step perturbations of the local covariance operator.

## Proof sketch
The proof structure is standard and should be expanded carefully in the theorem draft.

### 1. Spectral perturbation of eigenspaces
Because `L_t` and `L_{t-1}` are symmetric and satisfy the gap assumption, classical eigenspace perturbation results imply

```math
\|P_t-P_{t-1}\|_2 \lesssim \frac{\delta}{\gamma},
```

where `P_t = U_tU_t^\top` and `P_{t-1} = U_{t-1}U_{t-1}^\top` are the rank-`k` spectral projectors.

Likewise, the retained eigenvalues obey Weyl-type control:

```math
|\lambda_{t,i}-\lambda_{t-1,i}| \le \delta.
```

### 2. Stability of the diagonal transform
Since the composite scalar weight law is uniformly bounded and Lipschitz,

```math
\|W_t-W_{t-1}\|_2 \lesssim \delta + |r_t-r_{t-1}|.
```

If `r_t` is held fixed or chosen as a Lipschitz function of the retained spectrum, then this remains `O(\delta)`.

### 3. Decomposition of the retained REST operator
Write

```math
\mathcal{R}_t - \mathcal{R}_{t-1}
=
U_tW_tU_t^\top - U_{t-1}W_{t-1}U_{t-1}^\top.
```

Add and subtract intermediate terms to separate:
- diagonal-weight perturbation,
- basis/projector perturbation.

The first is controlled by `\|W_t-W_{t-1}\|_2`; the second by the projector perturbation bound and boundedness of `W_{t-1}`.

### 4. Output-coordinate bound
Since `z_t = W_tU_t^\top\tilde{x}_t`, the difference `z_t-z_{t-1}` splits into:
- change in weights/basis,
- change in retained coordinates of the centered input.

The claimed output bound follows by the triangle inequality and boundedness assumptions.

## Algorithm box
### Algorithm 1. REST in retained covariance coordinates
**Inputs**
- stream `(x_t) \subset \mathbb{R}^d`
- window length `m`
- retained rank `k`
- damping-scale rule for `r_t`
- lift gain `\beta`
- clipping bounds for reciprocal and exponential weights

**State**
- current window `W_t`
- current mean `\mu_t`
- current covariance operator `L_t`

**For each time `t`:**
1. Update the local window.
2. Compute the current mean `\mu_t`.
3. Form the centered covariance operator `L_t`.
4. Extract the top-`k` eigenpairs `(U_t, \Lambda_t)`.
5. Choose `r_t` using the prescribed rule.
6. Compute reciprocal weights and `D_{\mathrm{inv}}`.
7. Compute exponential weights and `D_{\exp}`.
8. Form retained coordinates `c_t = U_t^\top\tilde{x}_t`.
9. Emit REST coordinates `z_t = D_{\exp}D_{\mathrm{inv}}c_t`.

**Output**
- retained REST coordinate vector `z_t`

## Limitations
The present note leaves several things unresolved:
- long-horizon accumulation under repeated updates,
- angle-preservation claims,
- repeated-update near-isometry,
- behavior when the retained spectral gap collapses,
- whether the exponential lift helps more than it harms empirically,
- comparison to concrete baselines,
- and whether a genuinely non-commuting ordering effect exists outside the present diagonal retained-coordinate architecture.

That is acceptable for the current stage. This note is meant to produce one coherent preconditioning object, not a finished theory.

---

## What this note establishes
The repository now has a mathematically precise preconditioning object to work with:
- a covariance-based local operator,
- a retained-basis coordinate representation,
- explicit reciprocal and exponential diagonal maps,
- a composite geometric preconditioner,
- and a narrow first theorem target.

That is enough structure for theorem refinement, implementation analysis, and further architectural work.
